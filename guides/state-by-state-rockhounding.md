# Rockhounding by State: All 50 U.S. State Guides

Rockhounding conditions vary by state because geology, land ownership, access rules, mining history, public-land patterns and managed collecting opportunities are different across the country.

Use the state guide for the place you are actually visiting, then confirm the current rules for the exact collecting area before your trip.

## How to use a state guide

A useful state guide should help you move through four questions in order:

1. Which areas are worth researching?
2. What materials are associated with those areas?
3. Who manages the land or property?
4. What rule applies to the exact collecting activity you plan to do?

Do not stop at the first map result. A locality name can refer to a broad district, historic mine, road cut, stream, public parcel, private parcel or a site whose access has changed.
